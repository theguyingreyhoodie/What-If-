# What If Simulator

An alternate-history engine. Type a premise like *"What if the Library of Alexandria never burned?"* and it builds a chain of cause-and-effect events from the point of divergence onward. You can fork the timeline at any event, either with a new twist of your own or by letting the simulator pick a different outcome, and switch between branches.

Timelines are generated by Claude (Opus 5.5) using structured outputs. The reasoning summary streams into the UI while each timeline is being built.

## Features

- **Timeline generation**: point of divergence, summary, 8–10 events with category, impact and plausibility, plus an "our world vs. this one" comparison
- **Realism** (grounded / speculative / wild) and **time horizon** (decades / century / epic) controls
- **Branching**: fork any event, nest branches inside branches, switch between them or remove them
- **Live thinking**: Claude's summarized reasoning streams in while it works
- **History**: scenarios are saved in your browser (localStorage)
- **Export**: copy the currently visible path as Markdown
- **Demo mode**: canned data for trying the UI without an API key

## Getting started

Requires Node 20+.

```bash
npm install
cp .env.example .env      # then add your ANTHROPIC_API_KEY
npm run dev               # web on http://localhost:5173, API on :8787
```

No key yet? `npm run dev:demo` runs with canned timelines and makes no API calls.

### Production

```bash
npm run build
npm start                 # serves the built app and the API on :8787
```

## How it works

```
src/            React + Vite client
  model.ts      scenario tree: timelines, forks, visible-path flattening, Markdown export
  api.ts        reads the server's NDJSON stream
server/         Express API (keeps the API key server-side)
  simulator.ts  prompts + Claude calls (streaming, structured outputs, refusal fallback)
  demo.ts       canned responses for DEMO=1
shared/
  schema.ts     zod schemas used for request validation, Claude's output format, and client types
```

`POST /api/simulate` and `POST /api/branch` stream newline-delimited JSON: `thinking` lines while Claude works, then one `result` (or `error`) line. For a branch, the client sends the full path from the divergence to the fork point, plus what originally followed it, so the new branch goes somewhere different.

## Configuration

| Variable | Default | |
|---|---|---|
| `ANTHROPIC_API_KEY` | required | Your Claude API key |
| `CLAUDE_MODEL` | `claude-opus-5-5` | Model used for generation |
| `PORT` | `8787` | API server port |
| `DEMO` | unset | `1` serves canned data instead of calling Claude |

> The API has no auth or rate limiting. If you deploy it publicly, add both, or anyone can spend your API credits.
